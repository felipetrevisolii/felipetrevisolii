### 📌 Projeto em destaque

#### 🔎 [Jobs Hunter IA](https://github.com/felipetrevisolii/Jobs-Hunter-IA)

Sistema desenvolvido em Python para automatizar a busca e a organização de oportunidades de emprego e estágio na área de Tecnologia da Informação.

**Principais funcionalidades:**

- Coleta automatizada de vagas em diferentes fontes.
- Filtragem por área profissional, localização e requisitos.
- Avaliação e priorização das oportunidades.
- Registro de informações em banco de dados e Google Sheets.
- Notificações pelo Telegram.
- Identificação de vagas já processadas para evitar duplicidades.

O projeto reúne conceitos de automação, integração de sistemas, processamento de dados e organização de código.
